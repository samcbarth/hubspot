Marketing events: track webinars and their attendees in HubSpot

Marketing events are a CRM object for webinars and similar events, with registrations and attendance on each contact.

Short answer

HubSpot's developer docs describe a marketing event as a CRM object, like contacts and companies, that tracks events such as webinars with the contacts who registered and attended. Integrations create one with POST /marketing/v3/marketing-events/events, giving eventName, externalEventId, externalAccountId and eventOrganizer. In the app, find them under Marketing, Events.

1. Events in the app

My demo portal has two marketing events, both ongoing. The list uses object type 0-54 in its URL.

2. From an integration

POST https://api.hubapi.com/marketing/v3/marketing-events/events
{
  "eventName": "October webinar",
  "eventOrganizer": "Example Co",
  "externalEventId": "web-2026-10",
  "externalAccountId": "my-app-account"
}
