Two chatflows on the same page: set the priority

The higher priority chatflow wins.

Subscription
All chat tiers
Permissions
Chatflow access
Time
2 min · Beginner
Last verified
October 7, 2026

Short answer

HubSpot's KB: if two chatflows target the same page, or a contact meets both targeting rules, priority decides which appears. Reorder by value or drag, or use Move to top priority. Priority doesn't check team availability. To test, target a chatflow to a URL with a unique query parameter such as ?test_chat=true.
