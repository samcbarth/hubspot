Clone a HubSpot landing page for each location: what to change every time

One page you trust, many locations. Cloning is fast. Forgetting one field is how one location ends up with another location's phone number.

Subscription
Any tier with website or landing pages
Permissions
Create and edit pages
Time
10 min · Beginner
Validated
October 11, 2026, 5:30 PM ET

Short answer

Hover the row of the page in the page list and click Clone. In the clone's Settings, change the internal name, page title, URL, and meta description. Then replace every piece of location-specific content. Search the clone for the old location name before you publish.

1. Clone from the page list

Open Landing pages or Website pages. Hover the row of the page you want to copy and click Clone. The same row also offers Performance and Actions.

The clone opens as a draft. Publish it only after you have changed it.

2. Change the four settings

In the editor, click Settings in the top right. In the dialog, change these four on every clone:

  1. Internal page name, which only you see. It is how you tell the clones apart in the list.
  2. Page title, which appears in the browser tab when the page loads.
  3. Page URL. Choose the domain and enter a new URL slug for each clone.
  4. Meta description, the snippet that can appear in search results.

3. Change the content, not just the settings

Replace every location-specific detail: the name, address, phone number, pricing, images, maps, and any copy that mentions the location. Take each detail from a source you trust for that location. A short checklist helps:

  • Search the clone for the old location name before you publish.
  • Check the form. Confirm that leads reach the right place and carry the location tag your process needs.
  • Preview on desktop and mobile.
  • Keep a list of each clone's internal name and URL, so the next person can find them.
