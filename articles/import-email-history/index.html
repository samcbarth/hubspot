Import past emails, calls and notes onto records

Moving from another CRM? Activities can come over by import, not just records.

Short answer

HubSpot's import tool can import activities such as calls, emails, meetings, notes and tasks, associated to records by unique identifiers. HubSpot's KB recommends including Activity date so the activity shows when it actually happened. You can generate an example file with required properties at the start of the import.
