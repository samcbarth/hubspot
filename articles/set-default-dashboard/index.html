Set your default dashboard

Default is per user. Access is per dashboard.

Short answer

HubSpot's KB: choose Set as default on a dashboard and it's shown to you from then on when you open dashboards. Access options include Private to owner and View only for everyone; limiting to specific users and teams is Enterprise only.
