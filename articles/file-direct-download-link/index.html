Share a direct link to a file in HubSpot

Browsers decide whether it opens or downloads.

Subscription
All tiers
Permissions
Super Admin or View files permission
Time
2 min · Beginner
Last verified
October 7, 2026

Short answer

HubSpot's KB: you need Super Admin or View permission for files to get a direct link. There's no way to force a download without a server-side script, which the files tool doesn't support. Packaging the file as a .zip prompts a download in most browsers.
