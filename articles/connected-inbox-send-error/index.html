'This email couldn't be sent using your connected inbox'

Usually a send-as permission issue.

Subscription
All tiers
Permissions
Connected inbox; IT for Exchange
Time
2 min · Advanced
Last verified
October 7, 2026

Short answer

HubSpot's KB: the error usually means the user lacks permission to send as that address from a remote client; it's more common with Exchange. Use the HubSpot-Exchange inbox connection, or have IT assign permissions if connected through IMAP.

2. Worth knowing
