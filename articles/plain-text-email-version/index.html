Edit a marketing email's plain text version

Once edited, it stops updating.

Short answer

HubSpot's KB: a plain text version is auto-created and only shown where rich text isn't supported. Links show in full with tracking. Click tracking needs a setting. Once edited, it no longer updates from the main version.
