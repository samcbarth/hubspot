Where to store a contact's LinkedIn profile

There is already a LinkedIn URL property. You don't need to create one.

Subscription
All tiers
Permissions
Any user to edit; property settings to show it
Time
2 min · Beginner
Last verified
October 7, 2026

Short answer

HubSpot's default contact properties include LinkedIn URL, "the URL of the contact's LinkedIn page". In my demo portal it is a URL field type, so values are clickable on the record. Add it to record cards, views or forms rather than creating a duplicate custom property.
