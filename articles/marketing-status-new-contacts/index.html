Default marketing status for new contacts

Chatflows default to non-marketing; forms to marketing.

Subscription
Marketing Hub Starter and above
Permissions
Marketing contact settings
Time
2 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's KB: HubSpot forms and non-HubSpot forms set contacts as marketing by default; chatflows set them as non-marketing. You can change the default per form or chatflow. Some tools have a fixed default that can't be changed.
