Send a marketing email to more contacts

Short answer

HubSpot's KB: Actions > Send to more sends an already-sent email to more contacts, up to 100 times. Exclusions from the original send must be added again each time. Some email types can't use it.

The relevant screen in my demo portal.

2. Worth knowing
