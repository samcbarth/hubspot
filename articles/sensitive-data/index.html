Where Sensitive Data works in HubSpot

Not in chatbots, tokens, playbooks or sandboxes.

Subscription
Enterprise
Permissions
Super Admin to configure
Time
2 min · Advanced
Last verified
October 7, 2026

Short answer

HubSpot's KB: Sensitive Data isn't supported in chatbots, personalization tokens, playbooks or sandboxes; Highly Sensitive Data is more limited. Use field-level permissions. Don't store sensitive files in the files tool.
