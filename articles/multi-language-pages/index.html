Create multi-language versions of HubSpot pages

Language variations keep translated pages grouped with the original.

Subscription
All CMS tiers
Permissions
Page edit access
Time
4 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot lets you create language variations of a page so localized versions stay linked. The developer docs say a new variation is a copy of the source page's draft. To make another variation the main page, use Actions > Convert to language group primary. For headers and footers in global content, create language variations in the global content editor.
