Change lifecycle stages in bulk

Backwards moves need a clear first.

Short answer

HubSpot's KB: use an import, the index page or a workflow. Imports only move stages forward; to go backwards, clear the value first. In workflows, clear the property before setting the earlier stage.

2. Worth knowing
