HubSpot Sales Chrome extension not working

Check the Chrome profile first.

Subscription
All tiers
Permissions
Connected inbox user
Time
2 min · Beginner
Last verified

Short answer

HubSpot's KB: a working install shows the sprocket icon in the Chrome bar and in Gmail. Extensions are tied to a Chrome profile, so installing in one profile won't show it in another. Update to the latest version as a first step.
