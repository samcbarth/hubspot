HubSpot Sales Chrome extension not working

Update Chrome and the extension first, then check the profile and the logging settings that control what the extension logs.

Short answer

HubSpot's first step is to update Chrome and the HubSpot Sales Chrome extension. If it still fails, confirm you are signed into the Chrome profile where the extension is installed, and that Google's Rapid Release track is not in use, since HubSpot says that track is not compatible with the extension.

1. Update Chrome and the extension

HubSpot's troubleshooting guide starts with updating your Chrome browser and the extension. Do this before anything else.

2. Check the profile and the release track

Confirm the user is in the Chrome profile where the extension is installed. If the browser is on Google's Rapid Release track, switch to a supported channel. HubSpot's install guide notes the incompatibility directly.

3. Check the logging settings

The extension's logging behavior is set in HubSpot. Go to Settings, Objects, then Activities, and open Email Log & Track. The attachment setting and the default log setting for Sales Extension users both live here.
