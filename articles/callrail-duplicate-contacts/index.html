Call tracking is creating duplicate HubSpot contacts? Fix the source before you merge

The tool creates a contact with a made-up email, so it never matches the real contact with the same phone number. Merging without fixing the source just buys you a month.

Subscription
Professional or Enterprise for the duplicates tool; bulk merge needs Data Hub Professional or Enterprise
Permissions
Merge access to contacts; settings access in the call tracking tool
Time
25 min · Advanced
Validated
October 11, 2026, 6:35 PM ET

Short answer

Call tracking tools often create a contact with a placeholder email when the caller does not match an existing email. The new contact never matches the real one, so duplicates share a phone number. Group the duplicates by phone, sort each group into safe and needs-review, and merge only the safe ones. Then fix the source, or the duplicates keep coming back.

1. The symptom

The tool creates a contact with an auto-generated email address. HubSpot matches contacts on email and a few other properties, so the placeholder does not match the contact that already holds the caller's real email. Phone number is often the only field that links the two records. Past calls, texts, and notes end up split between them.

2. Group the duplicates by phone

Create a contact list of the records the tool created, sorted by phone number. The list shows the pairs and triples. Then check the duplicates tool. HubSpot's default rule compares first name, last name, email, phone number, zip code, company name, and IP country, so some of these pairs may already be in the review queue.

3. Sort each group

Phone alone cannot authorize a merge, and a name alone cannot either. Put each group into one of three piles:

  • Same person, messy name. Reversed order, a truncated name, or a misspelling. Normalize the name, then merge once a person confirms the match.
  • Carrier or placeholder text in the name field. A generic caller label, or a city and state typed into the name. The phone number is the only real evidence, so confirm before merging.
  • Different people on one number. A household, a shared office line, or a changed name. Leave these alone.

In one account I reviewed, most phone matches had names that needed cleaning before anyone could trust them. Only a small share matched on name and owner, so the rest went to a person for review.

4. Merge the safe groups

Use Review on a single pair to compare the two records and merge, or select several pairs and merge in bulk with a criterion such as Created first or Most recent engagement. Merges cannot be reverted. Write the list of pairs to a file first, note the count, and check the count afterward. Merge history can be exported from the duplicates tool.

Managing individual duplicates needs Professional or Enterprise. Bulk merging needs Data Hub Professional or Enterprise.

5. Fix the source

  • Turn off automatic contact creation in the tool, if the client accepts the trade-off. The tool then syncs only to contacts that already exist with a matching email, so new callers get no HubSpot record.
  • Add a custom duplicate rule. Data Hub Professional allows up to two custom rules per object and up to nine properties. A rule on phone number plus a normalized name gives a cleaner queue, but a shared number can still produce false matches.
  • Clean names on the way in. Normalizing name fields reduces the number of groups, but it changes live records, so test on a sample first.
Get approval first

Confirm the merge list with the account owner before you merge. HubSpot cannot undo a merge, and the owner knows which numbers belong to more than one person.
