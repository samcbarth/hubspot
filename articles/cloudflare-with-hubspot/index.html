Connecting a domain to HubSpot when DNS is on Cloudflare

Grey cloud, not orange, while connecting.

Subscription
All CMS tiers
Permissions
Domain settings access plus DNS access
Time
3 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's KB on updating DNS records, for Cloudflare: set Proxy status so the orange cloud turns grey, which lets HubSpot recognize the record. HubSpot also recommends a screenshot of your DNS settings before changes. Proxying through Cloudflare is a reverse proxy setup; Cloudflare Enterprise can use Orange-to-Orange.
