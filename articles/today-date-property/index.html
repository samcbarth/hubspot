There is no "today" property: use Time since and Time until instead

A common Community question: how to make a property that always holds today's date. HubSpot's answer is a calculation relative to today.

Subscription
Professional or Enterprise for calculation properties
Permissions
Edit property settings
Time
4 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot does not store a live "today" value on records. Instead, create a calculation property: Time since uses a date property as the start and today as the end; Time until uses today as the start. HubSpot's KB also describes relative time date properties. Raw duration values are stored in milliseconds, so formulas and filters may need millisecond values. Calculation properties need Professional or Enterprise.

1. Where to start

Create property, field type Calculation, in my demo portal.

2. Pick the right type

  • Days since last purchase: Time since, using the purchase date.
  • Days until renewal: Time until, using the renewal date.
  • Between two fixed dates: Time between.
