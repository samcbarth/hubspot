Limit which 2FA methods users can use

Browser logins only; the mobile app isn't limited.

Subscription
All tiers
Permissions
Super Admin
Time

Last verified
October 7, 2026

Short answer

HubSpot's KB: the setting is off by default, allowing all 2FA methods. It limits methods for browser logins only, not the mobile app. Users with a method that's no longer approved can log in once, then are prompted to set up an approved one.
