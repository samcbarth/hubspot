Run more than one knowledge base

Enterprise can run up to 100 knowledge bases.

Subscription
Service Hub Enterprise
Permissions
Super Admin or Knowledge base settings; Service Hub seat
Time
2 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's KB: create multiple knowledge bases to organize content for different audiences, products or brands. Service Hub Enterprise allows up to 100 knowledge bases and 10,000 articles per account. It needs a Service Hub seat and Super Admin or Knowledge base settings permission.

1. In HubSpot

The relevant screen in my demo portal.

2. Worth knowing

Professional accounts get one knowledge base. For languages instead of audiences, use multi-language articles.
