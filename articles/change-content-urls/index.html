Change a page's URL, domain or language slug

Each page's URL is edited in its settings. Change it, then redirect the old one.

Short answer

HubSpot's KB: in the content editor's settings, edit the URL slug and pick the domain; only primary and secondary domains set up for that page type are listed. Blog and knowledge base roots are changed in their own settings. Language variations use a language-specific slug. After a URL change, add a redirect from the old URL.
