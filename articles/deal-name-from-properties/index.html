Set a default deal name with tokens

Consistent deal names make board views and reports readable.

Short answer

HubSpot's KB: a default deal name, built from personalization tokens and static text, fills in when users create deals from existing contact, company, deal, ticket or custom object records. It needs Super Admin permissions. It applies to deals created manually on an associated record, so imports and workflows need their own naming. For workflows, set the name in the Create record action.
