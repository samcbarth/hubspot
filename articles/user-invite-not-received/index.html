A new user never got the HubSpot invite

Resend first. If the first delivery bounced, Support has to unblock it.

Short answer

HubSpot's KB: to resend, click Actions > Resend invite. If the invite was delivered but can't be found, send a reset password email. If the first delivery attempt fails, HubSpot blocks that address and you need HubSpot Support to fix it. Users who already have a HubSpot password can be added without an invite email.
