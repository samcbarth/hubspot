Adaptive page tests: test up to five landing page versions

Unlike a fixed A/B split, an adaptive test shifts traffic toward the version that converts.

Subscription
Content Hub Professional or Enterprise
Permissions
Page publish access
Time
4 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's KB: adaptive tests can run up to five page variations, and over time the best performer is shown more often. Every variation must include a form. All variations share the live URL with separate preview URLs. Publishing one variation makes all of them live, and after that you can edit them but not add, remove or rename variations. It needs Content Hub Professional or Enterprise.
