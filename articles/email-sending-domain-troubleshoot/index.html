Email sending domain won't verify

Hostnames without the domain.

Short answer

HubSpot's KB: DNS changes take time to propagate. Enter host(name) values without the domain, since some DNS providers append it and create a duplicated root domain. Check with tools like Dig. The DKIM CNAME records follow the DKIM protocol.
