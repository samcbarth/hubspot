Create a ticket (or deal) from a workflow

The new record is associated with the enrolled record by default.

Subscription
Ticket creation needs Service Hub Professional or Enterprise
Permissions
Workflows access
Time
3 min · Beginner
Last verified
October 7, 2026

Short answer

HubSpot's KB: tickets need a Ticket name and pipeline and status; deals need a Deal name and pipeline and status. New deals, tickets and companies default to the enrolled record's existing owner, and created records are associated with the enrolled record by default. Ticket creation is listed for Service Hub Professional and Enterprise.

2. Avoid duplicates
