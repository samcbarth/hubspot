Reuse workflow steps with Go to action

Point a branch at an action in another branch.

Subscription
Professional or Enterprise
Permissions

Time

Last verified

Short answer

HubSpot's KB: Go to action connects a branch to an action elsewhere, so you don't repeat the same steps. You can only pick actions in other branches, which prevents loops.
