Page shows an error in SEO recommendations

Robots.txt blocks are a common cause.

Subscription
All tiers with pages
Permissions
Pages access
Time
2 min · Intermediate

Short answer

HubSpot's KB: if a crawler can't index a page, it returns a crawling error. Rescan from the page's Optimization tab. For Scan blocked by robots.txt on an external page, add the HubSpot Crawler user agent as an exemption.

2. Worth knowing

The same errors can come from external tools like Semrush crawling HubSpot pages.
