Knowledge base visibility and search engine settings

The noindex setting covers search results pages only.

Subscription

Short answer

HubSpot's KB: a knowledge base can be public or restricted with SSO or access group membership, per knowledge base or article. The search setting only adds a noindex tag to the knowledge base search results pages; all other pages stay searchable unless restricted, for example in robots.txt.
