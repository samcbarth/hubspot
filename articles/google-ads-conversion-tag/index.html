Track Google Ads conversions on HubSpot pages

Don't also install the pixel through HubSpot.

Subscription
Professional or Enterprise
Permissions
Website settings for all pages
Time
2 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's KB: paste the global site tag in the site header HTML and the event snippet in thank you pages' head HTML. If you add the tag manually, don't also install the Google Ads pixel through HubSpot, or it fires twice.
