Search companies by name with the CRM search API

Use the search endpoint with a filter on name, or a free-text query.

Subscription
All tiers
Permissions
Company read scope
Time
3 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's developer docs: CONTAINS_TOKEN accepts * wildcards for partial matches. A free-text query searches each object's default searchable properties, which for companies include name, domain, website and phone. Queries max out at 3,000 characters and any query returns at most 10,000 results.

1. The request

POST /crm/v3/objects/companies/search
{ "filterGroups": [ { "filters": [
  { "propertyName": "name", "operator": "CONTAINS_TOKEN", "value": "acme*" } ] } ] }
