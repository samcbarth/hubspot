Make HubSpot pages more accessible

HubSpot gives you the tools. The templates and content still have to use them.

Short answer

HubSpot's developer guide covers text alternatives for non-text content (empty alt for presentational images), visible form labels instead of hiding them, a skip-to-content link, keyboard navigation, and semantic elements like proper table headers. HubSpot's KB adds that alt text helps both accessibility and SEO.
