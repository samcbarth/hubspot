Associate records automatically with a workflow

Match a property on both sides and the workflow builds the association.

Short answer

HubSpot's KB: Create associations links existing records, for example contacts and companies with matching Company name. Matching works with single-line text, multi-line text, phone, number, single checkbox and single select properties. For records the workflow creates, set the association in Create record instead. Workflows can also apply, update and remove labels.
