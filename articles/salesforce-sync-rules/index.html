Salesforce sync rules: two-way, prefer Salesforce, or don't sync

Each mapping has its own rule. Pick it per field.

Short answer

HubSpot's KB lists the update rules: Prefer Salesforce unless blank, Always use Salesforce, Two-way and Don't sync. Standard mappings can't be deleted, only set to Don't sync. Owner maps two-way only, with an exact match. Reference fields sync as 18-digit IDs, not labels.
