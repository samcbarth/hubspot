Prospecting agent: what it does and where to start

The agent researches target accounts and drafts outreach based on plays you write.

Subscription
Check access in your account; HubSpot Credits required
Permissions
Sales access
Time
4 min · Intermediate
Last verified
October 7, 2026

Short answer

Open Sales > Prospecting Agent. HubSpot's KB says it identifies good-fit companies from real-world triggers, sources contacts, and uses plays to guide research and outreach. Selling profiles let you tailor it by persona or product. Credits are consumed when it generates personalized outreach for each lead, and actions that need credits cannot run in sandboxes.

1. The start page

My demo portal shows the onboarding page with an offer of 14 days of free access.

2. Before you switch it on

  • Write plays with real ICP criteria.
  • Set a credit limit. See credits.

3. Related

Target accounts and Agent Hub context.
