Get recently created or updated contacts by API

Filter and sort the search API on lastmodifieddate.

Subscription

Permissions

Short answer

HubSpot's v1 lists migration guide: to retrieve recently updated records, filter by lastmodifieddate with the search API instead of the v1 recent endpoints. Search returns at most 10,000 results per query, so sync in time windows.

1. The request

POST /crm/v3/objects/contacts/search
{ "filterGroups": [ { "filters": [ { "propertyName": "lastmodifieddate", "operator": "GTE", "value": "2026-10-01T00:00:00Z" } ] } ],
  "sorts": [ { "propertyName": "lastmodifieddate", "direction": "DESCENDING" } ] }

2. Limits

See search limits.

3. Related
