Style a HubSpot form: where styles actually apply

On HubSpot pages, the form module's styles win.

Subscription
Raw HTML forms need Marketing or Content Hub Professional or Enterprise
Permissions
Edit forms permission
Time
3 min · Beginner
Last verified
October 7, 2026

Short answer

HubSpot's KB: themes and styles set in the form editor only apply to embedded forms or standalone form pages. Forms on HubSpot pages are styled with the form module style options. Only legacy forms can be set as raw HTML, which needs Marketing or Content Hub Professional or Enterprise.
