Test records before running enrichment

Personal email domains are excluded.

Subscription
All tiers to test; Starter+ to enrich
Permissions
Any user to test
Time
2 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's KB: any user can test. Records need a valid domain or email, and personal email addresses like Gmail are excluded. Running enrichment needs Starter or above.
