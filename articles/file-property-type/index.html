Store files on a record with a file property

A file property holds up to 10 files and can be filled from a form.

Short answer

HubSpot's KB: a File property stores files associated with a record. Each can contain up to 10 files. On records the upload limit is 20 MB with free tools and 50 MB with paid subscriptions; through a form it's 100 MB per file. You choose who can view the files when creating the property.
