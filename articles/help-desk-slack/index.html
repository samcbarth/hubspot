Manage help desk tickets in Slack

Add a sync per Slack channel with filters.

Subscription

Permissions

Short answer

HubSpot's KB: connect help desk to Slack to manage tickets and receive notifications there. Under Sync Help Desk tickets to Slack, click Add sync, set filters so the right tickets reach each channel, and edit syncs in the table view. Internal comments and notes sync.
