'This template doesn't allow modules to be added' in HubSpot: three causes

The editor opens, the page is blank, and it refuses to let you drop anything in. The page is rarely the problem.

Subscription
Any tier with website or landing pages
Permissions
Design Manager and page access
Time
15 min · Advanced
Validated
October 11, 2026, 5:25 PM ET

Short answer

The editor shows this message when it finds no drag and drop area it can use. Check three things: the template has no dnd_area, a layout the template extends does not resolve, or the dnd_column widths do not fit the 12-column grid. Fix the template, then create a new page from it. A page created while the template was broken may need to be recreated.

1. Start with a fresh page

Create a new page from Website pages or Landing pages, and open it in the editor. If a clone of a page that works loads its modules and a new blank page does not, the template is the likely cause.

2. Cause one: no drag and drop area

The template needs at least one dnd_area, which is where modules live. A minimal area looks like this:

{% dnd_area "main" %}
  {% dnd_section %}
    {% dnd_column %}
      {% dnd_row %}{% end_dnd_row %}
    {% end_dnd_column %}
  {% end_dnd_section %}
{% end_dnd_area %}

HubSpot's drag and drop reference describes the section, column, and row tags used inside an area.

3. Cause two: a broken extends path

If the template extends a layout file, the path must point to a real file in Design Manager. A path that resolves to nothing leaves the editor without a layout to render. Check the path against where the file lives, then re-upload the template. For a coded template picker problem, see coded template missing from the picker.

4. Cause three: columns that do not fit the grid

A dnd_column takes a width and an offset on a 12-column grid. Two columns that each take the full width of the row overlap. Give each column a width and an offset that fit inside the 12 columns:

{% dnd_column width=6, offset=0 %} ... {% end_dnd_column %}
{% dnd_column width=6, offset=6 %} ... {% end_dnd_column %}

After you re-upload the template, create a new page from it and check that the modules load. Pages built while the template was broken may need to be recreated.
