Make someone a Super Admin

Only a Super Admin can make another Super Admin.

Subscription

Time

Short answer

HubSpot's KB: users with Add and edit users permissions can only assign permissions they have, so you must be a Super Admin to assign Super Admin. A Super Admin can do virtually anything; a user with all permissions but not Super Admin still can't do some things. Removing Super Admin leaves the user with whatever permissions you assign.
