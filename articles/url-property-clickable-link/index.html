Make a property a clickable link with the URL field type

A text property holding a link is just text. The URL field type makes it a link.

Subscription
All tiers

Short answer

When creating a property, pick the URL field type for values that should open as links. HubSpot's own LinkedIn URL property uses it. Other field types listed in HubSpot's KB (single-line text, dropdown, multiple checkboxes and so on) store text or options and are not designed as links.
