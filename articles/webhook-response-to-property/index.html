Use a webhook's response later in the workflow

Test the webhook, choose outputs, then use them in Edit record.

Subscription
Data Hub Professional or Enterprise
Permissions

Short answer

HubSpot's KB: after testing a webhook, select which response fields to output for later actions; choose only fields present in every response. In a later action, open the data panel, go to Action data, select the Send a webhook action and use its properties.
