Deploy a HubSpot developer project with hs project upload

Apps, UI extensions and cards on the current developer platform ship as projects. The CLI uploads and builds them.

Subscription
All tiers with developer access
Permissions
Developer access and a personal access key
Time
4 min · Intermediate
Last verified
October 7, 2026

Short answer

hs project upload uploads the local project and triggers a new build in the target account. Use --account to pick production, a sandbox or a test account. Builds and the deployed build appear under Development, Projects. HubSpot's developer MCP server can also validate and upload a project.

1. The commands

npm install -g @hubspot/cli
hs account auth
hs project create
hs project upload --account=sandbox
hs project list-builds

2. Where builds show

Development, Projects in my demo portal lists a test project on platform version 2026.03 with its deployed and latest build.

3. Related

Test safely first in sandboxes and test accounts. An example project: a UI extension card.
