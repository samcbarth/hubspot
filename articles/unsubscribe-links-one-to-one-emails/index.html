Unsubscribe links in one-to-one and sequence emails

Sales emails can carry an unsubscribe link too, separate from marketing email footers.

Subscription
All tiers
Permissions
Super Admin and Account access for defaults
Time
3 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's KB: you can add an unsubscribe link to one-to-one emails, from records or sequences. Clicking it opens the unsubscribe page for that specific subscription type, with a link to manage other preferences. If data privacy settings are off, these links aren't included by default. Super Admin and Account access permissions are needed to manage the defaults.
