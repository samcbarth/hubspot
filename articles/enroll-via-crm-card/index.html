Enroll records in workflows from the record

Bypasses enrollment triggers.

Subscription
Professional or Enterprise
Permissions
Workflows plus Customize record page layout to set up
Time
2 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's KB: add an automation card under Enroll in Workflow to records, then enroll from the record. The workflow must match the object type. Records enroll even if they don't meet the triggers.
