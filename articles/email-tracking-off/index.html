Turn off one-to-one email tracking

Existing data stays.

Subscription
All tiers
Permissions
Super Admin
Time
2 min · Intermediate
Last verified
October 7, 2026

Short answer

HubSpot's KB: turning off tracking stops new opens and clicks being recorded; existing data remains. Users see an alert when sending. Attachment logging is a separate setting.

The relevant screen in my demo portal.

2. Worth knowing
